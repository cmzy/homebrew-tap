# cmzy/homebrew-tap

Homebrew casks for cmzy's apps.

## GeeTree

A pure-GPU-rendered, professional Git client: https://geetree.app

```sh
brew install --cask cmzy/tap/geetree
```

Upgrade with `brew upgrade --cask geetree`, remove with `brew uninstall --cask geetree`.
The cask installs the signed and notarised app for your Mac's chip (Apple silicon or Intel).
